# Changelog

## 0.1.0 — 2026-10-27

First release: 19 skills in six plugins (core, vulnerabilities, code, web, agents, response) on
`https://topy.ai/mcp/cso`, ported from Maggie Security — the daily CVE and end-of-life watch, CVE response with an
incident timeline, dependencies and package vetting, secrets (rotate first) and code patterns, a STRIDE threat model and
OWASP ASVS checklist, domain verification, headers, TLS and safe scans of verified domains, skill and MCP server vetting
(the App Factory gate), fix plans with fix-risk tiers and the weekly security report. The CSO never changes a server,
never scans an unverified domain and never prints a secret. Packages: `@topy-ai/cso-skills`, `@topy-ai/cso-mcp`,
`@topy-ai/cso-cli` 0.1.0.
